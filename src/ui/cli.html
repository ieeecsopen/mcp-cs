Command Reference
Command Description Options & Flags
mcs doctor Full repository health check, .env synchronizer, and lockfile auditor. --fix, --json
mcs ports Inspect all listening localhost sockets (:3000, :5432, :8080, etc.). --kill <port>, --json
mcs security-scan Entropy and regex analysis to detect leaked private keys and API tokens. --strict, --ignore <path>
mcs skills install Installs standardized skills into .agents/skills/ and Cursor rules. --all, --skill <id>
mcs --ui Spawns the local web dashboard for visual socket management and ERD studio. --port <num>, --no-open
