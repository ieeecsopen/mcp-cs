# Security Policy

The **IEEE Computer Society of SLIIT** and the MCP-CS maintainers take the security of our open-source tools seriously.

---

## 🛡️ Supported Versions

We actively release security patches and updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within `mcp-cs` (such as command injection, path traversal, or credential exposure):

1. **Do NOT report publicly on GitHub Issues.**
2. Please privately disclose the vulnerability to the maintainers via:
   - **GitHub Security Advisory**: [Submit a Private Advisory](https://github.com/ieeecsopen/mcp-cs/security/advisories/new)
   - **Email**: `ieee.cs@sliit.lk` or contact lead maintainer `@Hesara2003` on GitHub.

### What to include in your report:
- A description of the vulnerability and attack scenario.
- Steps or a minimal proof-of-concept (PoC) script to reproduce the issue.
- Potential impact on client environments or data security.

---

## ⏱️ Response Timeline

- **Initial Response**: Within 48 hours acknowledging receipt of report.
- **Triage & Verification**: Within 5 business days.
- **Patch Release**: Security updates will be tagged and published to NPM immediately upon verification.
