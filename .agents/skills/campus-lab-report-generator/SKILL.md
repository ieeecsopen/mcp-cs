# IEEE University Lab Report Generator

Use this skill when students need to prepare an academic practical lab report for submission.

## Standard Lab Report Structure

1. **Title & Header**:
   - Student Name, Student ID (Registration No.), Module Code & Name, Lab Number, Date.
2. **Objective**:
   - Clear statement of what the practical experiment or coding task aims to achieve.
3. **Apparatus / Technologies Used**:
   - Hardware, OS, runtime versions (Node.js, Python, GCC), and libraries.
4. **Methodology & Code Implementation**:
   - Well-commented core algorithms and architecture explanation.
5. **Experimental Results & Verification**:
   - Sample inputs, terminal outputs, screenshots, and testcase pass rates.
6. **Discussion & Error Analysis**:
   - Big-O analysis, bottlenecks encountered, and troubleshooting steps taken.
7. **Conclusion & References**:
   - Summary of key learning outcomes and IEEE citations.
