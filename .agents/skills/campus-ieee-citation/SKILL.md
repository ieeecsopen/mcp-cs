# IEEE Citation & Reference Formatter

Use this skill when students need to cite sources, libraries, datasets, and research papers in IEEE standard format.

## Reference Formats

- **Journal Article**:
  `[1] A. Author and B. Author, "Title of article," *Abbrev. Title of Journal*, vol. x, no. x, pp. xxx-xxx, Month, year, doi: 10.1109.xxx.`
- **Conference Proceeding**:
  `[2] A. Author, "Title of paper," in *Proc. Name of Conf.*, City, State/Country, year, pp. xxx-xxx.`
- **Online Software / GitHub Repository**:
  `[3] Author/Org, "Project Title," GitHub repository, year. [Online]. Available: https://github.com/org/repo. [Accessed: Month DD, YYYY].`
- **Book Chapter**:
  `[4] A. Author, *Title of Book*, xth ed. City, State, Country: Publisher, year, pp. xxx-xxx.`

## Procedure
1. Extract title, authors, publication venue, year, and URL/DOI.
2. Format entries sequentially numbered (`[1]`, `[2]`, `[3]`).
3. Verify alphabetization or order-of-appearance sorting.
