# University FYP & Capstone Architecture Planner

Use this skill when students are planning, architecting, or writing documentation for a university Final Year Project (FYP), software capstone, or research project.

## Step-by-Step Procedure

1. **Requirements & Scope Definition**:
   - Formulate Functional Requirements (FR) and Non-Functional Requirements (NFR).
   - Define User Personas and Core Use Cases.
2. **System Architecture Design**:
   - Design C4 model diagrams (Context, Container, Component).
   - Render Mermaid diagrams for API gateways, microservices, and database layers.
3. **Tech Stack Justification**:
   - Provide objective comparison matrices (e.g. PostgreSQL vs MongoDB, Next.js vs Vite, Fastify vs Express) with pros, cons, and academic citations.
4. **Data Schema & API Contracts**:
   - Model relational entities with primary/foreign keys and generate OpenAPI/Swagger endpoints.
5. **Generate SRS Chapter Outline**:
   - Draft IEEE Std 830-compliant Software Requirements Specification (SRS) chapters.
