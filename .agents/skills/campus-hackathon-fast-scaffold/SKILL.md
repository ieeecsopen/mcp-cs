# Rapid Hackathon Prototyping Scaffold

Use this skill during hackathons to build full-stack MVPs at maximum speed without boilerplate friction.

## 12-Hour Hackathon Speed Stack

1. **Frontend**: Vite + React or Next.js App Router with Tailwind CSS.
2. **Backend**: Fastify / Express or Next.js Route Handlers with Zod validation.
3. **Database**: Supabase / SQLite / PostgreSQL with Prisma or Drizzle ORM.
4. **Mock Data First**: Seed sample datasets immediately with `api_generate_mock_data` to unblock frontend development.
5. **Deploy Early**: Deploy to Vercel/Render at hour 2 to avoid last-minute deployment panic.
