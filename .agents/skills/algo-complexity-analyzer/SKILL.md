# Algorithmic Complexity Analyzer

Use this skill when optimizing algorithms for competitive programming or high-throughput backends.

## Procedure
1. Identify loop bounds, recursion depth, and dynamic memory allocations.
2. Evaluate worst-case Time Complexity ($O(1)$, $O(\log N)$, $O(N)$, $O(N \log N)$, $O(N^2)$).
3. Evaluate Space Complexity (auxiliary space vs input buffers).
