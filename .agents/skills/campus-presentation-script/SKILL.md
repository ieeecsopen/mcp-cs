# Project Defense & Viva Presentation Script Generator

Use this skill when students need to prepare slides and speaking notes for project grading, viva examinations, or hackathon judging.

## 10-Minute Slide & Pitch Structure

- **Slide 1: Hook & Title (0:00 - 1:00)**: Problem statement and real-world impact.
- **Slide 2: Proposed Solution (1:00 - 2:30)**: System overview and core value proposition.
- **Slide 3: System Architecture (2:30 - 4:00)**: Technical design, databases, and APIs.
- **Slide 4: Live Demo / Walkthrough (4:00 - 7:00)**: Highlight 2-3 key user flows.
- **Slide 5: Performance & Challenges (7:00 - 8:30)**: Big-O scaling, bottlenecks resolved, security.
- **Slide 6: Conclusion & Future Scope (8:30 - 10:00)**: What was achieved and next steps.
- **Q&A Defense Guide**: Anticipated questions from academic examiners and strong defense answers.
