# Data Structures & Algorithms Visualizer

Use this skill to explain algorithms and data structures to university students with step-by-step ASCII memory traces.

## Supported Visualizations

- **Linked List Operations**: Pointer manipulation (`prev -> curr -> next`) during insertions, deletions, and reversals.
- **Binary Search Trees (BST)**: Tree balancing, AVL rotations, and in-order traversals.
- **Dynamic Programming (DP) Tables**: Grid state transitions with formula breakdowns.
- **Graph Traversal Traces**: BFS queue states and DFS recursion stack call traces.
