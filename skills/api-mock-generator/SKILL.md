# Synthetic API Mock Data Generator

Use this skill when prototyping frontend interfaces without a live backend API.

## Procedure
1. Choose the entity schema (`users`, `products`, `posts`, `transactions`).
2. Call `api_generate_mock_data` specifying the count (1-50).
3. Inject the mock JSON into frontend components or state stores.
