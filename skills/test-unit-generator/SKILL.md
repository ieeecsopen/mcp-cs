# Automated Unit Test Generator

Use this skill when writing unit tests for utility functions, algorithms, and business logic.

## Test Structure
1. **Arrange-Act-Assert (AAA)** pattern.
2. **Happy Path Tests**: Typical expected inputs and outputs.
3. **Edge Case Tests**: Empty strings, `null`/`undefined`, negative numbers, max constraints.
4. **Failure & Error Handling**: Verify functions throw expected error instances and codes.
