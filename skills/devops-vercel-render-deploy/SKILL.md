# Cloud Deployment & Hosting Setup

Use this skill when deploying web apps and backend services to cloud platforms.

## Deployment Matrix
- **Frontend / Next.js**: Vercel / Cloudflare Pages.
- **Background Workers / APIs**: Render / Railway with persistent disk or Docker runtime.
- **Relational Database**: Supabase (PostgreSQL) / Neon serverless DB.
- **Environment Variables**: Configure production secrets and sync with local development.
