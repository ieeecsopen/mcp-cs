# Modern Frontend & SaaS UI Design Skill

Use this skill when building web frontends, dashboards, landing pages, or UI component systems.

## Design Rules
1. **Typography Hierarchy**: Use modern sans-serif fonts (Inter, Plus Jakarta Sans, Outfit) with strict scale (`text-xs` to `text-3xl`).
2. **Neutral & Accent Palettes**: Obsidian dark background (`#050505`, `#0f172a`), subtle border outlines (`rgba(255,255,255,0.08)`), and electric accents (amber/yellow `#ffd000` or violet).
3. **Card Glassmorphism**: `backdrop-blur-md` with translucent backgrounds (`bg-neutral-900/60`).
4. **Interactive States**: Hover transitions (`transition-all duration-200 hover:-translate-y-0.5`).
